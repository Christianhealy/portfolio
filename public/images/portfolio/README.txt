Drop your photos in this folder.

1. Add a file here, e.g. photo4.jpg
2. Open public/portfolio.json and add an entry:
   {
     "id": "6",
     "type": "image",
     "title": "My New Photo",
     "mediaUrl": "/images/portfolio/photo4.jpg",
     "category": "Portrait"
   }

For videos, set "type": "video" and use an embed URL, e.g.
https://www.youtube.com/embed/VIDEO_ID  or  https://player.vimeo.com/video/VIDEO_ID
